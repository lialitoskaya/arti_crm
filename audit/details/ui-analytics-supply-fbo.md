# UI/UX аудит (часть A): Аналитика, Поставки (beta), Поставки FBO Ozon

База: рабочее дерево ветки `feat/ozon-fbo-supplies` (коммит 38b34e3), аудит по коду без браузера.
Файлы: `app/static/index.html`, `app/static/app.js`, `app/static/styles.css` (далее `index`, `app`, `css`).
Проверено против `docs/UI_DESIGN_STANDARDS.md`; исключения чатов учтены по `audit/chat-exclusions.md`
(общие `button`, `label`, `.panel-card`, `.status-badge`, `notify`, токены — только через scoped-вариант раздела).

Опорные факты, на которые ссылаются строки ниже:

- `--crm-muted` в light-теме = `#7a879b` (css:3287, переопределяет css:15) → на белом 3,64:1, ниже AA 4,5:1 для текста < 18 px.
- Базовый `label` = 13 px, `--crm-text-soft` (css:171); базовый `button` 34 px, `button.small` 28 px (css:70–88); `.status-badge` 11 px (css:444–457).
- `button:disabled { opacity: .55 }` (css:88); единственный focus-индикатор — `button:focus-visible { box-shadow: var(--crm-focus) }` (css:170).
- `prefers-reduced-motion` в `styles.css` отсутствует (grep: 0), `button:hover { transform: translateY(-1px) }` (css:85) — общий слой.
- `html[data-theme] .panel-card { backdrop-filter: blur(18px) }` (css:3471–3480) + полупрозрачный `--crm-panel` (css:3277) — glassmorphism на всех карточках всех разделов; общий компонент.
- `notify()` = `alert()` (app:753–757) — общий канал ошибок.

## Аналитика

Коротко: менеджер открывает «Аналитика», задаёт период/маркетплейс/часы, читает 8 KPI-плиток, график по часам,
таблицу по дням и разбивку по маркетплейсам, затем проверяет расчёт в drilldown (до 1000 строк) и открывает чат.
Данные: `/api/analytics/chats` и `/api/analytics/chats/drilldown?limit=1000&include_excluded=1` (app:6358–6368).
Кнопки в разделе: 4 варианта — primary с иконкой `.analytics-refresh-btn` (без своего CSS → базовый чёрный), `ghost small` «Все часы»,
`secondary small» («Обновить строки», «Открыть» в строках), кастомные `button.analytics-hour-button`.
