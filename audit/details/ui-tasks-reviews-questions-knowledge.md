## Итог

1. Всего 55 замечаний: high — 10, med — 31, low — 14; 11 из них требуют scoped-варианта, потому что задевают общие с чатами хелперы/правила (`notify`, `setStatus`, `.panel-card`, базовые `button/input`, семейство бейджей, `.chat-time`, `.reviews-list`, `.date-range-filter-*`, `button.small`).
2. Top-1: канал обратной связи для не-чатовых разделов — toast-вариант вместо `alert()`/невидимого `setStatus` + inline-валидация пустых полей (закрывает 2 high и ~8 med во всех четырёх разделах).
3. Top-2: списки отзывов/вопросов — `grid-auto-rows:auto` scoped на `#reviewsView/#questionsView`, строки как `<button>` с клавиатурой, и запрет полной пересборки `renderQuestionsList` при фокусе в inline-форме (3 high).
4. Top-3: мобильные сценарии — CSS для `.knowledge-chip*` и focus-trap/Escape для dialog/листа базы знаний, свёртывание липкой панели фильтров задач на ≤760 (3 high).
5. Отдельно к ревью: подтверждение удаления задачи подставляет имя клиента вместо текста задачи (js:5711–5712) — однострочный фикс с высоким риском ошибочного удаления.
