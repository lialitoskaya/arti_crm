# UI/UX аудит, часть C: оболочка приложения, вход, сотрудники, тех. настройки, профиль

База: рабочее дерево на `38b34e3` (`feat/ozon-fbo-supplies`). Аудит по коду без браузера; номера строк — `app/static/index.html`, `app/static/app.js`, `app/static/styles.css`. Там, где вывод сделан по каскаду CSS, а не по прямому правилу, стоит пометка «проверить в браузере». Раздел чатов вне scope (`audit/chat-exclusions.md`); для каждой строки указано, затрагивает ли исправление общий с чатами компонент/токен/функцию.

Контрастные значения посчитаны по формуле WCAG для токенов светлой темы на белой панели (`--crm-panel: rgba(255,255,255,.92)` ≈ белый).

## 1. Оболочка: навигация, темы, токены

Коротко: сотрудник весь день переключается между разделами через левую панель; на 901–1080px она схлопывается в иконки, на ≤900px превращается в фиксированную нижнюю полосу (`styles.css:2222–2269`). В этой же панели живут тема, уведомления, статус синхронизации, «Обновить» и «Выйти». Темы включаются скриптом `theme-init.js`, поэтому слой `html[data-theme]` (3270–3599) активен всегда и перекрывает базовые правила 1–1357.
