# Инструкции к старым выпускам

Здесь сохранены исходные заметки к версиям v54–v103 и их исправлениям. Дата, команды и пути в каждой заметке относятся к соответствующему выпуску. Пути к файлам проекта указаны относительно корня CRM.

Действующие инструкции по установке, настройке прав и тестированию собраны в [README проекта](../../../README.md).
