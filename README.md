# Arti CRM

CRM для сотрудников, которые отвечают покупателям на Ozon, Wildberries и Яндекс Маркете. Коннекторы загружают события маркетплейсов в SQLite. Из этой базы интерфейс читает переписку, задачи и данные для аналитики.

## Локальный запуск на Windows

Из корня отдельной локальной копии проекта установите зависимости в виртуальное окружение.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для первого запуска с пустой базой задайте в локальном окружении `BOOTSTRAP_ADMIN_USERNAME` и `BOOTSTRAP_ADMIN_PASSWORD`. При последующих запусках CRM использует уже созданные учётные записи. Требования к начальному логину и паролю описаны в [руководстве по установке](docs/HOSTING_UPGRADE.md#first-administrator-on-an-empty-database).

Запустите сервер и откройте `http://127.0.0.1:8000`. Параметр cookie в примере предназначен для локального HTTP.

```powershell
$env:CRM_COOKIE_SECURE = "0"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## Работа в CRM

- В чатах сотрудники отвечают покупателям, назначают ответственных и ведут задачи. Первый успешный ответ из CRM может назначить автора ответственным за свободный чат. [Правила работы с данными](docs/BUSINESS_RULES.md)
- Администратор задаёт права на разделы в карточке сотрудника. Они действуют при входе по паролю и через Яндекс. [Права сотрудников](docs/EMPLOYEE_SECTION_PERMISSIONS.md)
- Аналитика считает первое входящее сообщение покупателя в чате за локальный день как одно обращение. Детализация загружается при открытии. [Определения метрик](docs/ANALYTICS.md) · [Загрузка детализации](docs/ANALYTICS_LAZY_LOADING.md)
- Для поставок FBO доступны расчёт, подтверждение и история прогонов. [Работа с поставками Ozon](docs/OZON_FBO_SUPPLIES.md)
